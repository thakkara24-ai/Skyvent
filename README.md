# SKYVENT — Part 1: Frontend Member & Authentication

## Assigned role
Frontend Developer 1 — Authentication + Member Experience.

## Included working scope
- Authentication: login, registration, email verification, forgot password
- Public landing/about/event/shop pages used by the member experience
- Member dashboard
- Membership
- My tickets
- My orders
- Notifications
- Profile
- Shared React context, layouts, components and API service required to run this part

## Run
```bash
npm install
npm run dev
```

The frontend expects the backend API configured in `.env` based on `.env.example`.
