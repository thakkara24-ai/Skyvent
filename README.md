# Member 4 — Frontend Lead: Member Experience

## Actual owned code
- `src/pages/auth/` — register, login, OTP verification, forgot password
- `src/pages/member/` — dashboard, membership, profile
- `src/pages/public/LandingPage.jsx` and `AboutPage.jsx`
- shared `context/`, `services/`, `components/`, member/public layouts

## Run
```powershell
cd frontend
npm install
npm run dev
```
Open `http://localhost:5173/`. API is configured for backend member workspace on port 8001.
